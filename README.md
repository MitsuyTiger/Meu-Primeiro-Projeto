# 🎮 Pedra, Papel ou Tesoura

Este é um jogo simples feito em **Python**, desenvolvido como parte do Projeto Integrador da **Gran Faculdade**.

## 🧠 Sobre o projeto
O jogo permite que o jogador escolha entre **pedra**, **papel** ou **tesoura**, enquanto o computador faz uma escolha aleatória.  
O resultado mostra se o jogador **venceu**, **empatou** ou **perdeu**, e o placar é atualizado a cada rodada.

## 🚀 Como executar
1. Copie o código do arquivo `Pedra Papel ou Tesoura`.
2. Cole em um compilador Python online (como [Python Compiler](https://www.pythoncompiler.io)) ou execute no seu computador com Python instalado.
3. Digite sua escolha e veja o resultado!

## 🏆 Funcionalidades
- Escolha interativa do jogador  
- Escolha aleatória do computador  
- Comparação automática das jogadas  
- Placar de vitórias e derrotas
